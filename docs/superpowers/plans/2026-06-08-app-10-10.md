# App 10/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convertir Ganancias JABA en una aplicacion profesional, protegida, auditable y validada contra el flujo real del estudio.

**Architecture:** El plan se ejecuta por unidades cerradas P18 a P25, siempre contra Docker local o staging, nunca contra Hostinger productivo durante pruebas. Cada unidad debe incluir TDD cuando cambie comportamiento, documentacion de cierre, verificacion fresca, commit y push.

**Tech Stack:** Next.js 16, React 19, Prisma 7, MySQL/MariaDB, Docker, Vercel, GitHub Actions, Vitest, TypeScript.

---

## Scope

Este plan no implementa todos los cambios en una sola unidad. Define el orden y los entregables. Cada Pxx debe generar su propio plan corto si requiere muchas modificaciones.

- [ ] **Step 1: Write failing auth tests**

Create `src/domain/ganancias/tests/auth.test.ts`:

```ts
import { describe, expect, it } from 'vitest';
import { hashPassword, verifyPassword } from '../auth/password';

describe('password auth', () => {
  it('verifies the right password and rejects the wrong one', async () => {
    const hash = await hashPassword('ClaveSegura2026!');
    await expect(verifyPassword('ClaveSegura2026!', hash)).resolves.toBe(true);
    await expect(verifyPassword('otra-clave', hash)).resolves.toBe(false);
  });
});
```

Run:

```powershell
npm run test -- src/domain/ganancias/tests/auth.test.ts
```

Expected: FAIL because `../auth/password` does not exist.

- [ ] **Step 2: Implement password/session helpers**

Add a minimal secure helper using Node crypto `scrypt` or a vetted dependency if installed intentionally.

- [ ] **Step 3: Add login/logout routes and middleware**

Protect all dashboard and API routes except `/login` and `/api/auth/login`.

- [ ] **Step 4: Seed initial admin only in Docker/staging**

Never commit real production password.

- [ ] **Step 5: Verify access**

Expected:

- anonymous request to `/api/clientes` is rejected;
- authenticated request works;
- dashboard redirects to `/login` if no session exists.
